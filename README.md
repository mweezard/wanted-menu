# Blade ball

Меню v1.6: полёт с тумблером и ползунком скорости 30–120, отдельная вкладка **Autoparry**, настройки оформления. Обучающие подписи удалены. Backspace переключает видимость меню; ввод текста сохраняет обычное поведение клавиши.

**Autoparry — экспериментальная функция.** При включении она отслеживает распознанный мяч, направленный на игрока, оценивает сближение с учётом сетевой задержки и отправляет импульс блока F. Скрытие меню сохраняет её работу. Доступность синтетического ввода и объектов мяча проверяется при выполнении; состояние отображается в меню. Отправленное нажатие не означает подтверждённое успешное отбивание. Текущая совместимость с Blade ball, серверные тайминги и особые способности не проверены запуском в игре.

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/mweezard/blade-ball-menu/main/BladeBallMenu.client.luau"))()
```

Загрузчик требует среды с клиентскими `loadstring` и `game:HttpGet`; обычный LocalScript Studio этот формат не поддерживает.

В `main` хранится один актуальный скрипт. Повторный запуск удаляет предыдущий интерфейс и останавливает его функции; история Git сохраняется. Код проверяется компилятором Luau, статическим аудитом и тестами логики с имитацией объектов. Эти проверки не заменяют запуск Roblox.
