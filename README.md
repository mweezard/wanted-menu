# Blade ball

Меню для тестовой сессии Roblox. На главной — только переключатель **полет** и скорость полёта. В настройках — анимации интерфейса, уведомления и акцентный цвет.

## Управление

- `Right Shift` — показать или скрыть меню. Экранная кнопка `BB` открывает скрытое меню.
- `полет` — включение и выключение на главной вкладке.
- `W` / `S` — движение вперёд и назад по направлению камеры, включая высоту.
- `A` / `D` — движение в стороны.
- Тело повторяет поворот и наклон камеры. Для поворота камеры мышью используются обычные настройки управления Roblox.
- Без нажатых WASD персонаж зависает на месте. Скорость меняется на главной странице рядом с переключателем полёта: 30 / 60 / 90 / 120 studs/s.

## Загрузчик

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/mweezard/blade-ball-menu/refs/heads/main/BladeBallMenu.client.luau"))()
```

Этот формат требует среды, предоставляющей клиентские `loadstring` и `game:HttpGet`; в обычном LocalScript Roblox Studio он не работает. Для своего плейса вставьте содержимое `BladeBallMenu.client.luau` в LocalScript внутри `StarterPlayer > StarterPlayerScripts`.

## Обновления

В ветке `main` хранится один актуальный файл меню. При повторном запуске скрипт удаляет предыдущий экземпляр интерфейса и отключает его полёт. История изменений сохраняется в Git.

Синтаксис проверяется официальным компилятором Luau. Работа в самом плейсе Blade ball не проверена; серверные правила перемещения могут ограничивать полёт. Специфичные игровые механики плейса не подключены.
